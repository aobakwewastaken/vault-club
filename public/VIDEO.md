# Hero image

Add your hero background image as **`hero.jpg`** (or `hero.webp`) in this folder.

- Use a running or group fitness image to match the [Vault Strength Club](https://www.vaultstrengthclub.run/) vibe.
- The image fades in and scales in on load; content animates in after.
- If the file is missing, the hero falls back to the dark gradient only.
